# Exercice - Analyse de formations en entreprise

## Objectif

Créer un tableau croisé dynamique à partir d'une liste de demandes de formation.

## Données

Importer ou ouvrir le fichier `demandes_formations.csv` dans Excel.

## À produire

- Créer un TCD qui compte les demandes par `Catégorie personnel` et `Origine demande`.
- Ajouter une synthèse des `Heures` par `Domaine formation`.
- Modifier au moins une fois les champs du TCD.
- Actualiser le TCD après modification du CSV ou de la source importée.
- Créer un graphique croisé dynamique simple.
