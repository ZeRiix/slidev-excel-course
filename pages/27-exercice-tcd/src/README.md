# Exercice - Analyse de formations en entreprise

## Objectif

Créer un tableau croisé dynamique à partir d'une liste de demandes de formation.

## Données

Importer ou ouvrir le fichier `demandes_formations.csv` dans Excel.

## À produire

- Créer un TCD qui compte les demandes par `Categorie personnel` et `Origine demande`.
- Créer une synthèse de la somme des `Heures` par `Domaine formation`.
- Ajouter un filtre ou un segment permettant d'explorer les résultats.
- Modifier une valeur dans la source, puis actualiser le TCD.
- Créer un graphique croisé dynamique lisible.

## Repères

- Pour la première analyse, utiliser `Demande` dans `Valeurs` avec l'opération `Nombre`.
- Pour la deuxième analyse, utiliser `Heures` dans `Valeurs` avec l'opération `Somme`.
- Le filtre ou segment doit aider à isoler une partie des données, par exemple un service, une origine ou une catégorie.
- Vérifier l'agrégation choisie automatiquement par Excel.
- Après modification de la source, actualiser le TCD et le graphique croisé dynamique.
