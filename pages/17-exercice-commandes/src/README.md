# Exercice - Analyse de commandes

## Objectif

Calculer automatiquement les statuts, les priorités et les totaux par ville.

## Données

Importer ou ouvrir le fichier `commandes.csv` dans Excel.

## À produire

- `Statut` : `"Réglé"` si payé, sinon `"À relancer"`.
- `Priorité` : `"Haute"` si montant `> 1000` et non payé, sinon `"Normale"`.
- Nombre de commandes à Paris avec `NB.SI`.
- Montant total des commandes à Paris avec `SOMME.SI`.
